# 기획서

## 한 줄 소개
사소한 고민을 올리면 모르는 사람들이 몇 초 만에 골라주는 고민 투표 앱

## 목적
백엔드 포트폴리오. 화면보다 설계(포인트 원장, 동시성, 개인정보 암호화)와 문제 해결 과정을 보여주는 것이 목표.

## 타겟
연애·인간관계, 옷, 카톡 멘트처럼 가볍지만 혼자 결정하기 애매한 고민이 있는 20~30대

## 기존 서비스와의 차이
- 인스타 스토리 투표: 지인만 봐서 솔직한 답이 안 나옴
- 에브리타임·블라인드 투표: 특정 집단 안에서만 돌고 글을 읽어야 함
- 네이트판: 긴 글과 댓글 위주
- **이 앱: 모르는 사람의 솔직한 의견을, 글 읽는 부담 없이, 몇 초 만에**

## MVP 기능

| # | 기능 | 설명 |
|---|---|---|
| 1 | 회원 | 가입, 로그인(JWT), 휴대폰 번호 인증 |
| 2 | 고민 올리기 | 텍스트형(선택지 2~4개) / 사진형(정확히 2장) |
| 3 | 투표 피드 | 탭으로 선택, 위로 올리면 다음 고민. 2지선다는 좌우 스와이프로도 선택. 선택 즉시 결과 % 표시 |
| 4 | 내 고민 결과 | 내가 올린 고민의 투표 현황 |
| 5 | 포인트 | 투표하면 적립, 내 고민 상단 노출에 사용 (현금화 없음) |
| 6 | 지인에게 숨기기 | 내 연락처에 있는 사람에게 내 고민을 노출하지 않음 |
| 7 | 신고·차단 | 부적절한 고민 신고, 사용자 차단 |

## 콘텐츠 규칙
- 사진형: 얼굴 대신 옷만 나오도록 크롭 유도
- 카톡 멘트: 캡처 업로드 대신 보낼 문장만 입력 (제3자 개인정보 보호)
- 텍스트 선택지: 20자 제한

## 개인정보 설계
- 회원 휴대폰 번호: AES 암호화 + HMAC(검색용) 저장
- 연락처: 원본 저장 없이 HMAC만 저장, 가입 회원은 회원 ID로 매칭
- 암호화 키는 코드가 아닌 환경변수로 분리

## 이후 추가 기능
랭킹(주간/월간), 결과 알림, 카테고리·태그, 연령·성별별 결과 분석, AI 밸런스게임 질문, 한 줄 조언

## 기술 스택
- Backend: Java, Spring Boot, JPA, Gradle(Groovy), Flyway
- DB: MariaDB, Redis(성능 개선 단계)
- Frontend: React Native(Expo) 또는 React 모바일 웹 (지인 숨기기 기능 여부에 따라 결정)
- Infra: Docker Compose, GitHub Actions

4. 핵심 기능 개발: 회원 → 고민 등록 → 투표 → 결과 → 포인트
5. 테스트 + CI
6. 성능·동시성 개선 (부하 테스트 → 개선 → 수치 기록)
7. 화면 + 배포 + 샘플 데이터
8. README, Swagger, 트러블슈팅 글 정리
