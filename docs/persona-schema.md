# AI 페르소나 변수 스키마 (변수 뼈대)

AI 페르소나 기능의 인물을 만들 때 쓰는 변수 15개. "변수 뼈대 + 경험 살" 방식의 ①~③ 에 해당한다.
코드는 `spikes/persona-format/schema.py` 이고, 이 문서의 수치를 그대로 쓴다. 분포는 공개 통계에 맞추되, 못 찾은 것은 **가정** 으로 표시했다.

- 모든 인물은 가상이다. 실존 인물·실제 상호·개인정보를 넣지 않는다.
- 성향 점수(②)는 내부 보관용이다. 프롬프트에는 점수를 넣지 않고, ④ 에서 행동 문장으로 바꿔 넣는다.
- 통계 출처는 문서 끝의 목록 참고. 인용 수치는 2026-09-30 기준으로 확인한 것이다.

## 3. ④ 점수 → 행동 문장

성향 6개 중 50 에서 먼 순서로 4개를 골라, 구간(낮음/중간/높음)별 문장 목록에서 하나씩 뽑는다(시드 고정). 문장은 "그 사람이 실제로 하는 행동" 으로만 쓰고, 성별·나이를 이유로 대지 않는다. 목록은 `schema.py` 의 `BEHAVIORS`.

예: 신중함 77 → "물건 하나 사기 전에 후기를 세 번은 찾아본다", 전통 지향 35 → "결혼이나 출산은 하고 싶은 사람만 하면 된다고 말한다".

(a) 라벨 형태에서는 같은 순서로 상위 2개를 형용사로만 쓴다: "신중한 편, 개방적인 편".

## 4. ⑤ 경험 서술과 ⑥ 검수 (요약, 결과는 `docs/persona-format-bench.md`)

- 페르소나마다 5개 주제(연애·소비·직장·취미·가족) 중 4개를 시드로 지정하고, exaone3.5:7.8b 가 주제당 1~2문장(40~90자)의 1인칭 장면을 JSON 으로 쓴다. 기혼이면 연애 이야기는 배우자와, 솔로면 현재 연인 없음 등 관계 규칙을 프롬프트에 넣는다.
- 검수: (1) 정규식 — 고정관념 표현("여자라서", "나이 들어서"), 실존 이름, 한국어 아님, 성향을 설명하는 문구("~편이라"), 길이. (2) LLM 추출 — 이야기에 배우자·자녀·연인·직장·지역이 나오는지만 뽑고, 설정과의 모순은 코드가 판정한다. 걸리면 최대 2회 다시 쓴다.
- LLM 에게 모순 판정까지 맡기면 안 된다: 7.8B 모델은 "남자친구" 를 배우자로 보고 "~일 수 있음" 을 문제로 적어 30명 전원을 탈락시켰다.
